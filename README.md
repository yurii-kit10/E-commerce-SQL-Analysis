# E-commerce SQL Analysis

У цьому проєкті я зібрав чотири SQL-запити для аналізу інтернет-магазину. Дослідив email-розсилки, розподіл доходу, виконання прогнозу та події на сайті.

## Дані та інструменти

Використав Google BigQuery і GoogleSQL. Запити працюють із набором даних `DA`, який містить інформацію про сесії, покупки, товари, акаунти, листи, події та прогноз доходу.

## Що я зробив

1. **[Акаунти та email-розсилки за країнами](sql/01_email_metrics_by_country.sql)**  
   Порахував акаунти, надіслані листи, відкриття та переходи. Визначив рейтинги країн за кількістю акаунтів і надісланих листів.

2. **[Дохід за пристроями та континентами](sql/02_revenue_by_device_and_continent.sql)**  
   Розрахував дохід за континентами, окремо виділив дохід із мобільних і настільних пристроїв. Додав частку загального доходу та показники акаунтів і сесій.

3. **[Виконання прогнозу доходу](sql/03_revenue_prediction_fulfillment.sql)**  
   Порівняв накопичений розрахований дохід із накопиченим прогнозом і визначив відсоток його виконання за датами.

4. **[Згадки YouTube у назвах сторінок](sql/04_youtube_page_title_share.sql)**  
   Знайшов згадки YouTube у назвах сторінок із параметрів подій і розрахував їхню частку за континентами.

## SQL-навички

У запитах використав `JOIN`, `GROUP BY`, `CASE`, CTE, `UNION ALL`, віконні функції, роботу з датами та `UNNEST` для вкладених даних.

## Як запустити

Кожен запит можна відкрити в папці `sql`, скопіювати в редактор Google BigQuery та виконати окремо. Для запуску потрібен доступ до набору даних `DA`.
